This file summarizes the licensing notices that apply to uVim.  It exists so

`:help uganda` resolve inside this tree.

Summary

1. Unmodified copies may be used and redistributed.

2. When redistributing uVim, preserve the applicable copyright and license
   notices in the distribution.

3. When redistributing a modified version, make it clear that it was modified.
   The original Vim license also expects modified distributors to keep contact
   information and to make their changes available under terms compatible with
   upstream integration.

4. This help entry is a guide for users and distributors.  It does not replace
   the notices embedded in source files, documentation headers, or other
   per-file licensing statements.

Project guidance

If you ship binaries, source archives, runtime files, container images, or
packages built from this repository:

- Keep this help file and other upstream notices in the distributed runtime.
