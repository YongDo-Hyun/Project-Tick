README_unix.txt for version 7.4 of uVim: Micro Vi IMproved.

This file explains the installation of uVim on Unix systems.
See "README.txt" for general information about uVim.


When you use the source distribution, "make install" is used to install uVim.
See the "INSTALL" file in the "src" directory.

If you use a compiled package, follow the instructions for the package.
