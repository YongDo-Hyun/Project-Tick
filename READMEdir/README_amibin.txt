README_amibin.txt for version 7.4 of uVim: Micro Vi IMproved.

See "README.txt" for general information about uVim.
See "README_ami.txt" for installation instructions for the Amiga.
These files are in the runtime archive (vim60rt.tgz).


The Amiga "bin" archive contains the uVim executable for the Amiga.  It was
compiled with "big" features.

Postscript printing is not included to avoid requiring floating point
computations.
