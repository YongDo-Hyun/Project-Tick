## How to Contribute to bzip2

Thanks for your interest in contributing to **bzip2**.

### 1. Build the project

Before making any changes, ensure that you can successfully build the project.

Please follow the instructions in [COMPILING.md](COMPILING.md).

Verify that the build completes without errors.

---

### 3. Make your changes

* Keep changes minimal and focused
* Follow existing coding style
* Avoid introducing unnecessary dependencies
* Ensure compatibility with musl (if relevant to your fork)

---

### 4. Validate your changes

Before submitting:

* Rebuild the project
* Re-run tests
* Check for regressions

---

### 5. Submit your contribution

* Write a clear commit message
* Please dont forget sign off your commits and <bzip2:> prefix.
* Explain *why* the change is needed, not just *what* changed
* Reference related issues if applicable

---

### Notes

* This project prioritizes simplicity and portability
* Contributions that increase complexity without strong justification may be rejected
